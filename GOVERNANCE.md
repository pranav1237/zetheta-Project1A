# Repository Governance Checklist

Before submission:

- [ ] Repository is private.
- [ ] Only authorised collaborators are present.
- [ ] Branch protection is enabled.
- [ ] Direct pushes to the default branch are restricted.
- [ ] Forking is disabled where organisational settings permit.
- [ ] Public wiki/discussions are disabled.
- [ ] Secrets are stored only in secret-management facilities.
- [ ] Raw customer/PII data are absent.
- [ ] Final README and report are complete.
- [ ] Reproduction commands have been tested.
- [ ] Model limitations are documented.
- [ ] Repository transfer is performed only through the authorised Zetheta process.

Repository settings cannot be enforced by this codebase alone; verify them in GitHub before submission.
